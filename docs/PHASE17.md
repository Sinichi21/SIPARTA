# Phase 17 — Register & Rekap Persuratan

Fitur:
- satu halaman register untuk Surat Masuk, Surat Keluar, dan Surat Terbit;
- tab tipe dokumen;
- filter pencarian, tahun, bulan, jenis surat, dan status;
- statistik tahunan;
- status dokumen terbit aktif/dicabut;
- export CSV sampai 5.000 baris sesuai filter aktif;
- permission memakai `reports.view` dan `reports.export`;
- sidebar ditambah menu `Register Persuratan` di grup Rekap & Laporan.

Tidak ada perubahan schema database.
