# Phase 18 — Dashboard Persuratan & Workflow

Menjadikan dashboard utama lebih operasional tanpa menghapus ringkasan SPT.

Fitur:
- Ringkasan Surat Masuk aktif;
- jumlah Surat Keluar yang masih dalam workflow;
- jumlah Surat Terbit bulan berjalan;
- jumlah dokumen yang sudah dicabut;
- antrian Surat Masuk;
- antrian workflow Surat Keluar;
- Surat Terbit terbaru;
- shortcut Catat Surat Masuk, Surat Keluar Baru, SPT Baru, Register Persuratan;
- aktivitas audit mengenali IncomingLetter, OutgoingLetter, dan IssuedLetter.

Tidak ada migration dan tidak mengubah CSS global.
